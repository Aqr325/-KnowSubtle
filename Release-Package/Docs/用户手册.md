# WordCosmos Learning Universe 用户手册

> 个性化资源生成与学习多智能体系统 · Windows 桌面版

---

## 1. 简介

WordCosmos Learning Universe 是一款面向个人学习者的桌面软件。它内置一个基于多智能体（MetaGPT）的学习引擎，配合电影感仪表盘，提供：

- **统计概览**：每日学习时长、单词量、正确率。
- **每日目标**：番茄钟、单词、分钟数的环形进度。
- **词库管理**：单词标记、按保留率筛选、批量管理。
- **艾宾浩斯复习**：基于遗忘曲线的到期复习提醒与复习会话。
- **番茄钟**：可配置工作时长 / 短休息 / 长休息，阶段自动循环并回写目标进度。
- **知识图谱 / 星球系统 / 词云 / 日历**：多维可视化学习轨迹。
- **多智能体聊天**：规划师、资源师、评测师、导师、画像师、知识官 6 个 Agent。

软件以"本地服务 + 原生桌面窗口"方式运行：主程序在后台启动一个本地 HTTP 服务，并用系统原生 WebView2 渲染桌面窗口（无浏览器地址栏/标签页）打开仪表盘，呈现真正的桌面应用体验，无需手动部署服务器。

## 2. 系统要求

| 项目 | 最低要求 |
|------|----------|
| 操作系统 | Windows 10 / 11（64 位） |

## 3. 安装

### 方式一：免工具安装（推荐，无需 NSIS）

1. 进入 `Release-Package/Install/`，**右键 `install.bat` →「以管理员身份运行」**。
2. 脚本自动完成：复制全部文件到 `C:\Program Files\WordCosmos Learning Universe`、静默安装 `vc_redist.exe`、创建开始菜单与桌面快捷方式、写入卸载注册表。
3. 安装完成后即可从开始菜单或桌面快捷方式启动。

### 方式二：标准 NSIS 安装包

1. 在**已安装 NSIS** 的机器上执行 `makensis.exe Release-Package/Install/install.nsi`，生成 `WordCosmos-Setup.exe`（输出到 `Release-Package` 的上级目录，避免被自身递归打包）。
2. 双击 `WordCosmos-Setup.exe` 按向导安装。

> 开发者模式：本机执行 `python build/build_exe.py` 生成 `Core/main/main.exe`（onedir 单文件夹）；随后可直接用方式一安装，或安装 NSIS 后用方式二生成安装包。

## 4. 启动与使用

- 双击开始菜单快捷方式（或 `Core/main/main.exe`），主程序启动本地服务并在**原生桌面窗口**（WebView2 渲染，无浏览器）打开仪表盘；若本机未装 WebView2，则自动回退打开默认浏览器访问 `http://127.0.0.1:8000/`。
- 首次启动会在用户目录 `%APPDATA%/WordCosmos/` 下创建 `Config/`、`Data/`、`Logs/`。
- 关闭桌面窗口即退出程序；若回退到浏览器模式，关闭浏览器标签不会停止服务，请在任务管理器结束 `main.exe`。

## 5. 配置说明（Config/config.json）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `app_name` | string | WordCosmos Learning Universe | 应用显示名 |
| `port` | int | 8000 | 本地服务监听端口（被占用时自动 +1） |
| `host` | string | 127.0.0.1 | 监听地址，桌面软件建议仅本机 |

高级配置（可选，写入 `Config/config.json` 或环境变量）：

- `LAS_RESOURCE_DIR`：自定义前端 HTML 目录（覆盖 Resources/html）。
- `LAS_DATA_DIR`：自定义学习数据存储目录（覆盖 AppData/WordCosmos/Data）。
- LLM 接入：在 `local_metagpt` 或对应配置中填入 `base_url` / `api_key` 以启用真实 AI。

`Config/app.key` 为密钥文件，用于未来会话签名 / 数据加密占位，请勿外泄。

---

## 6. 数据与隐私

- 学习数据默认存储在 `%APPDATA%/WordCosmos/Data/`（用户级，随账户）。
- 所有计算在本地完成；仅在配置了真实 LLM API 时才会将学习内容发送到对应云服务。
- 可在「设置」中导出 / 清除学习数据。

## 7. 常见问题（FAQ）

**Q：打开后窗口空白 / 无法访问？**
A：确认 `main.exe` 已在运行（任务管理器存在进程）。原生窗口模式请检查系统是否具备 WebView2 运行时（Win10/11 通常已内置；缺失会自动回退浏览器）；也可尝试手动访问 `http://127.0.0.1:8000/`。检查端口是否被占用或防火墙拦截。

**Q：界面显示「Out of Memory」？**
A：点右上角 ⚡ 性能按钮关闭磨砂玻璃与动画；或改用 `Resources/html/index-safe.html` 安全版。

**Q：如何卸载？**
A：开始菜单「卸载」或「控制面板 → 程序和功能」。

**Q：想自定义前端？**
A：替换 `Resources/html/` 下的 `index.html` / `landing.html` / `profile.html` 即可，无需重新编译主程序。

## 8. 卸载

- 通过系统「程序和功能」或安装时写入的卸载项移除（方式一、方式二均注册了标准卸载信息）。
- 也可直接**以管理员身份运行** `Release-Package/Install/uninstall.ps1` 卸载。
- 卸载将删除安装目录与开始菜单/桌面快捷方式及注册表项；用户数据（`%APPDATA%/WordCosmos/`）默认保留，可手动清除。
