# M2 搜索与问题求解 · 模块概述

## 一、模块教学目标

本模块承接绪论，聚焦"如何用计算手段求解智能任务"这一核心问题。搜索是人工智能最基础的问题求解范式：将问题形式化为状态空间，再用系统化的搜索策略寻找从初始状态到目标状态的路径。

完成本模块后，学生应能够：

1. 用"状态、动作、状态转移、目标测试、路径代价"五要素形式化一个问题；
2. 区分无信息搜索（广度、深度、一致代价等）与有信息搜索（A*、贪婪）；
3. 理解启发式函数的作用及其"可采纳性/一致性"条件；
4. 了解对抗搜索（极小化极大、α-β 剪枝）与约束满足问题（CSP）的基本思想；
5. 认识搜索与后续机器学习/智能体模块的关联。

## 二、核心知识点清单

- 问题形式化：状态空间、动作、转移模型、目标、代价
- 无信息（盲目）搜索：BFS、DFS、一致代价搜索（UCS）
- 有信息（启发式）搜索：贪婪最佳优先、A* 算法
- 启发式函数：可采纳性（admissible）、一致性（consistent）
- 对抗搜索：极小化极大（Minimax）、α-β 剪枝
- 约束满足问题（CSP）：变量、约束、回溯 + 启发式

## 三、与前后续模块的关系

- **前置**：M1 绪论建立智能体概念。
- **后续衔接**：
  - M3 知识表示与推理将"状态"升级为"符号知识"；
  - M4/M5 机器学习用数据驱动替代手工启发式；
  - M8 智能体在更复杂环境中做序列决策（与对抗搜索、强化学习呼应）。

## 四、思政 / AI 素养融入点

1. **系统思维**：将复杂现实问题抽象为"状态—动作"模型，培养化繁为简、抓住主线的工程素养。
2. **权衡意识**：盲目搜索与启发式搜索的代价/收益权衡，类比"蛮力 vs 巧思"，引导学生既尊重规律又讲求方法。
3. **公平与博弈伦理**：对抗搜索揭示零和博弈逻辑，启发学生思考合作博弈、多方共赢的现实治理意义。

## 五、学习建议

建议手绘一个"八数码/迷宫"的小状态空间图，分别用 BFS 与 A* 走一遍，直观体会"启发式如何剪枝"。搜索是后续许多算法的思维原型。
