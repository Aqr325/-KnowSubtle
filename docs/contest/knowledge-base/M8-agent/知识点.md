# M8 智能体与大模型应用 · 核心知识点

## 1. 什么是智能体（Agent）

智能体是能在环境中**自主感知并采取行动**以达成目标的系统。经典属性：
- **自治性（Autonomy）**：无需人类持续干预；
- **反应性（Reactivity）**：感知环境并响应；
- **主动性（Proactivity）**：主动发起目标导向行为；
- **社会性（Social ability）**：与其他 Agent/人交互。

现代 **LLM Agent** 以大模型为"认知中枢"，叠加规划、记忆与工具。

## 2. LLM Agent 的三大模块

- **规划（Planning）**：把复杂任务分解为子任务；常用**思维链（CoT）**让模型"一步步想"：
  $$\text{CoT:}\quad\text{问题}\rightarrow \text{推理步骤}_1\ldots\text{步骤}_k\rightarrow\text{答案}$$
  **ReAct** 范式进一步将"推理（Thought）"与"行动（Action）"交替：思考→调工具→观察→再思考。
- **记忆（Memory）**：短期（当前上下文窗口）+ 长期（外部向量库/数据库），使 Agent 跨会话保持知识。
- **工具（Tools）**：通过**函数调用（Function Calling）**调用搜索、计算器、API、代码执行等，突破纯文本推理局限。

## 3. 检索增强生成（RAG）

解决 LLM "知识截止 + 易编造"的痛点：
1. **索引**：将文档切分、向量化存入向量数据库；
2. **检索**：用户提问时检索最相关片段（如余弦相似度）；
3. **增强生成**：把检索片段作为上下文拼入提示，让模型"据检索内容作答"。

$$\text{answer}=LLM(\text{query}\oplus \text{Retrieve}(\text{query}))$$

> 关键结论：RAG 让回答**可溯源、可更新、可私有化**，是降低幻觉、接入企业/课程知识库（如本系统 KnowSubtle）的主流方案。

## 4. 提示工程与对齐

- **提示（Prompt）**：用自然语言刻画任务、角色、约束与输出格式；
- **指令微调（SFT）/RLHF**：让模型遵循指令、符合人类偏好（见 M5/M6）；
- **系统提示注入**：在系统层约束模型"不确定时标注 [待核实]、不编造引用"，即本系统防幻觉思路（见 D2 §3.3）。

## 5. 多智能体协作

多个角色 Agent（如"规划者/执行者/批评者"）通过消息协作，可提升复杂任务质量（如辩论纠错、流水线分工）。需注意通信开销与一致性。

## 6. 关键风险（衔接 M9）

- **幻觉与误用工具**：错误检索或未校验即执行动作；
- **失控/越权**：自主执行带来不可逆后果；
- **提示注入攻击**：外部内容操控 Agent 偏离本意；
- **过度依赖**：用户让渡判断力，削弱自身能力。
