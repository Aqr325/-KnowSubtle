# M4 机器学习基础 · 核心知识点

## 1. 三类学习范式

- **监督学习**：数据为 $(x_i,y_i)$ 带标签，学映射 $f:x\mapsto y$（分类/回归）。
- **无监督学习**：仅 $x_i$，学数据内在结构（聚类、降维）。
- **强化学习**：智能体通过与环境交互获得奖励，学策略 $\pi$ 最大化累积回报（详见 M8）。

## 2. 线性模型与激活

**线性回归**：$\hat y=w^\top x+b$，参数最小化均方误差

$$\mathcal L_{\text{MSE}}=\frac1n\sum_{i=1}^n(y_i-\hat y_i)^2$$

**逻辑回归（二分类）**：用 sigmoid $\sigma(z)=\frac1{1+e^{-z}}$ 输出概率

$$\hat p=\sigma(w^\top x+b),\qquad \hat y=\begin{cases}1,&\hat p\ge0.5\\0,&\text{否则}\end{cases}$$

## 3. 损失函数

- 回归常用 **MSE**；
- 分类常用 **交叉熵（Cross-Entropy）**：对二分类
  $$\mathcal L=-\frac1n\sum_i\big[y_i\log\hat p_i+(1-y_i)\log(1-\hat p_i)\big]$$
  多分类用 softmax + 负对数似然。

> 关键结论：损失函数量化"当前模型有多差"，优化目标即最小化其在训练集上的平均（经验风险）。

## 4. 梯度下降

参数沿损失负梯度更新：

$$\theta\leftarrow\theta-\eta\,\nabla_\theta \mathcal L(\theta)$$

其中 $\eta$ 为**学习率**。$x\leftarrow$ 表示参数更新。三种变体：
- **批量（BGD）**：用全量数据算梯度，稳但慢；
- **随机（SGD）**：每样本更新，快但噪声大；
- **小批量（mini-batch）**：折中，深度学习默认。

> 易错点：$\eta$ 过大易震荡不收敛，过小收敛慢；可通过学习率调度改善。

## 5. 过拟合、泛化与正则化

- **过拟合**：训练误差低但测试误差高（"死记"噪声）。
- **欠拟合**：两类误差都高（模型太简单）。
- **偏差—方差权衡**：偏差高→欠拟合；方差高→过拟合。
- **正则化**：在损失中加惩罚项，如 L2（岭，$\lambda\|\theta\|^2$）、L1（套索，促稀疏）。

## 6. 评估指标（分类）

- 准确率 $\text{Acc}=\frac{TP+TN}{TP+TN+FP+FN}$
- 精确率 $P=\frac{TP}{TP+FP}$，召回率 $R=\frac{TP}{TP+FN}$
- F1 = $\frac{2PR}{P+R}$，调和平均
- ROC-AUC 衡量排序质量

> 易错点：类别不平衡时准确率有误导性（如 99% 负类全判负即得 99% 准确率却无意义），应看精确率/召回率/AUC。

## 7. 经典算法速览

- **k-近邻（kNN）**：基于邻域投票，惰性学习；
- **决策树**：按信息增益/基尼不纯度递归划分；
- **k-means**：迭代分配—更新簇心的无监督聚类；
- **朴素贝叶斯**：基于特征条件独立假设与贝叶斯公式。
