# M6 自然语言处理 · 案例

## 案例一：神经机器翻译与 Seq2Seq + 注意力（Google 神经翻译，2016）

**背景**：2016 年 Google 将搜索翻译全面切换为神经网络翻译（GNMT），质量大幅跃升。此前基于短语的统计机器翻译（SMT）难以捕捉长距离语序与语义。

**技术点**：
- 采用 **Seq2Seq**：编码器（LSTM/Transformer）把源语言句子编码为上下文向量，解码器据此逐词生成目标语言。
- 引入**注意力机制**：解码每一步动态聚焦于源句最相关的词，解决"定长向量信息瓶颈"，显著提升长句翻译。
- 训练数据为海量平行语料（如 WMT），并用"零样本跨语言"等技巧处理低资源语言对。

**启发**：
1. 注意力机制本是 NLP 为解决翻译对齐而生，后来被 Transformer 发扬光大、反哺全部序列任务，体现"具体问题→通用机制"的创新扩散。
2. 翻译质量的提升直接降低了跨语言信息壁垒，具鲜明的"技术普惠"与"文明互鉴"价值。
3. 局限：翻译仍会犯常识性错误、在专名/文化负载词上失真，提示"流畅≠准确"，使用者需结合领域校验。

## 案例二：BERT 与预训练语言模型的"理解革命"（2018）

**背景**：2018 年 Google 提出 BERT，在 11 项 NLP 任务上刷新 SOTA，开启了"预训练 + 微调"的统一范式，影响延续至今。

**技术点**：
- 预训练任务 **MLM（掩码语言模型）**：输入中约 15% 词被 [MASK]，模型据双向上下文预测原词，从而学到深层双向语义表示。
- 另一任务 NSP（下一句预测，后续研究对其必要性有争议）建模句间关系。
- 下游只需在预训练底座上接一个小分类/抽取头并微调，即可适配情感分析、问答、NER 等任务。

**启发**：
1. "先在大文本上自监督学通用语言知识，再小数据微调"极大降低了任务定制成本，是当代 NLP 工程的标准套路。
2. BERT 与 GPT 的"理解 vs 生成"分工，帮助学生建立"任务决定架构选择"的工程直觉。
3. 衔接 M8/M9：这类基础模型既是能力源泉，也携带语料偏见与能耗/版权争议，技术选型须兼顾效能与责任。

> 小结：从 Seq2Seq 注意力到 BERT/GPT 预训练，NLP 完成了"特征工程→表示学习→基础模型"的跃迁；语言成为人机最自然的交互界面，也为智能体（M8）提供了认知与表达的核心能力。
