# M6 自然语言处理 · 模块概述

## 一、模块教学目标

本模块将深度学习（M5）应用于人类语言，介绍让机器"理解、生成、翻译"文本的核心技术与范式演进，从词向量到预训练语言模型。

完成本模块后，学生应能够：

1. 理解自然语言处理的层次（词法→句法→语义→语用）与基本任务；
2. 掌握词向量（Word2Vec）与分布语义思想；
3. 理解 RNN/CNN/Transformer 在 NLP 中的演进；
4. 描述预训练语言模型（BERT/GPT）的原理与差异；
5. 认识 NLP 的典型应用（翻译、问答、摘要、对话）及局限（歧义、偏见、幻觉）。

## 二、核心知识点清单

- 任务谱系：分词、词性、句法分析、命名实体、情感分析、机器翻译、问答
- 词表示：独热 → 词向量（Word2Vec / GloVe）；分布假设
- 序列建模：RNN/LSTM、CNN-for-text、Seq2Seq + 注意力
- 预训练语言模型：BERT（编码器，MLM）、GPT（解码器，自回归）
- 评测：BLEU、ROUGE、困惑度（Perplexity）
- 提示（Prompt）与指令微调简介（衔接 M8）

## 三、与前后续模块的关系

- **前置**：M4（表示学习）、M5（Transformer）是本课技术底座。
- **后续衔接**：
  - M7 处理另一种"序列/网格"模态（视觉）；
  - M8 以 LLM 为智能体的语言认知与行动规划核心；
  - M9 关注语言模型偏见、歧视与有害内容生成。

## 四、思政 / AI 素养融入点

1. **语言与文化自信**：中文 NLP 面临分词、字本位、低资源语言等独特挑战，鼓励学生投身中文信息处理与 multilingual 公平。
2. **求真与反幻觉**：语言模型"一本正经编造"的特性，培养学生交叉验证、溯源引用的信息素养。
3. **包容与反歧视**：训练语料的刻板印象会被模型习得并放大，树立"技术内含价值观"的清醒认知。

## 五、学习建议

建议从"词向量类比（king - man + woman ≈ queen）"体会分布语义的魅力，再理解为何 Transformer 能捕捉上下文；可试用开源小模型做一次文本分类或翻译，观察其成败边界。
