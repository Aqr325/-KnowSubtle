# M5 深度学习 · 模块概述

## 一、模块教学目标

本模块是机器学习的深化，聚焦以深层神经网络为代表的表示学习方法，解释其为何在大数据时代爆发，并介绍 CNN、RNN、Transformer 等关键结构与训练机制。

完成本模块后，学生应能够：

1. 描述神经元、多层感知机（MLP）与激活函数的作用；
2. 理解反向传播（BP）与梯度下降的训练机制；
3. 区分 CNN（局部权享）、RNN/Attention（序列建模）的适用场景；
4. 简述 Transformer 的自注意力机制及其革命性意义；
5. 认识大模型（LLM）与预训练—微调范式的基础。

## 二、核心知识点清单

- 神经元与激活：sigmoid / tanh / ReLU
- 多层感知机（MLP）与万能近似定理
- 反向传播算法（链式法则）
- 卷积神经网络（CNN）：卷积、池化、权值共享
- 循环网络（RNN/LSTM）与序列建模局限
- Transformer：自注意力（Self-Attention）、多头、位置编码
- 训练技巧：批归一化、Dropout、优化器（Adam）

## 三、与前后续模块的关系

- **前置**：M4 提供损失、梯度下降、过拟合等基础。
- **后续衔接**：
  - M6 NLP 与 M7 CV 是深度学习在两大感知领域的工程展开；
  - M8 以 Transformer/LLM 为智能体的"认知引擎"；
  - M9 讨论深度模型的对抗脆弱性、能耗与偏见。

## 四、思政 / AI 素养融入点

1. **底层创新价值**：深度学习突破源于算法（BP、ReLU、Attention）、数据、算力三者的长期积累，弘扬"坐得住冷板凳"的基础研究精神。
2. **自主可控算力观**：大模型依赖高端算力与开源生态，引导学生关注芯片、框架等基础软硬件的自主可控战略意义。
3. **批判使用意识**：深度模型"黑箱"、易被骗（对抗样本），培养"不盲目信任模型输出、重视验证"的科学态度。

## 五、学习建议

建议先理解 MLP 的"前向传播—算损失—反向传播"闭环，再分别看 CNN 如何利用图像局部性、Transformer 如何摆脱序列依赖。可借助可视化工具（如注意力热力图）建立直觉。
