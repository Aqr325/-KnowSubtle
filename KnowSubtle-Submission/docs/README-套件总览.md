2. **测试数字可溯源**：D5 初稿引用的"55/55 ALL PASS"在源文件 `RELEASE_PACKAGE_REPORT.md` 中无据，已统一修正为报告真实表述——"打包产物独立验证全绿（全部路由 HTTP 200、离线 demo 流水线端到端跑通并落盘）"；D3 仅引用可核验事实（verify_all.py ~50 check、流式 mock 12 断言、node --check、CI verify.yml），不杜撰精确总数。
3. **D3 落盘修复**：D3 测试说明书首次撰写出现静默失败（报告"完成"但文件未写盘），已重撰并确认落盘（200 行）。
4. **缺陷追踪**：D3 §7 记录真实缺陷 D3-001（moderation.py 漏 `from typing import Any` 致启动崩溃，已修复），作为质量闭环证据。
