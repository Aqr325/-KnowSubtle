# 智能学习界面「打不开」问题复现与定位报告

> 复现日期：2026-07-19
> 结论先行：**当前磁盘上的 `learning.html` 代码本身可正常打开**（已用无头 jsdom 真实加载验证：已登录态 0 报错、DOM 完整）。"依旧打不开"的真实原因是**运行中的实例加载了陈旧副本**——QWebEngine 的磁盘 HTTP 缓存（`DiskHttpCache`）复用旧版页面，或 exe 进程未重启/未硬刷新。

---

## 一、访问入口与复现步骤

**入口（两种）**
1. 桌面端：双击 `启动KnowSubtle.bat` → 启动 exe（PyQt6 + QWebEngineView 内嵌浏览器）→ 加载 `index.html`（登录页）→ 点导航「🧮 智能学习」（`index.html` 链接指向 `learning.html`）。
2. 浏览器/直接访问：`http://127.0.0.1:8753/learning.html`（需先登录拿到 `wc_auth_token`）。

**复现步骤**
1. 启动 exe，在 `index.html` 登录 / 注册账号；
2. 点击「智能学习」进入 `learning.html`；
3. 观察现象：是白屏、被踢到某页、还是控制台报错。

## 三、定位结论（根因）

1. **当前 served 代码本身正确、可打开**（上述全部证据）。
2. **"依旧打不开" = 运行实例加载了陈旧副本**，两种具体情形：
   - **A. QWebEngine 磁盘缓存复用旧页（主因）**：`launcher.py:772` 启用了 `DiskHttpCache`，且原 `app.py` 的 HTML 路由只发 `no-cache`（Chromium 可能复用已缓存的旧 `learning.html`）；该缓存在 exe **重启后仍残留磁盘**，导致即使我改了磁盘文件，WebView 仍吐旧页。
   - **B. 旧进程未重启 / 未硬刷新**：用户跑的是改文件前的 exe 进程，内存中仍是旧页面。
3. **关键架构事实**：HTML 运行时从 `Release-Package/Resources/html/` **按请求实时读盘**（不被打进 exe，`build_exe.py` 注释与 `_resolve_resource_dir` 均已确认）；但 `app.py` / `launcher.py` 是**被打包进 exe 内部**的。因此：
   - 对 `learning.html` 的修改 → **立即对运行中的 exe 生效**（读盘）；
   - 对 `app.py`(no-store) / `launcher.py`(清缓存) 的修改 → **必须重新构建 exe 才对 exe 生效**。

---

## 四、已验证的修复步骤

### 4.1 立即生效（HTML 读盘，对当前 exe 有效）
- `escHtml` 提升到脚本最顶部 + 全局 `unhandledrejection`/`error` 兜底 → 解决「Promise 未处理拒绝: escHtml is not defined」。
- 4 处未登录/登录失效跳转由 `landing.html` → `index.html`（landing 是纯介绍页无登录入口，曾造成登录死胡同）→ 打通「智能学习」入口。
- 对所有 `localStorage` 访问（`Auth Guard`、`initTheme`、`apiFetch`、`authFetch`、`streamConverse`、`streamGenerate`）加 `try/catch` → 杜绝 `localStorage` 不可用导致的白屏（已用 jsdom 模拟 `localStorage` 抛错验证：0 报错、页面正常渲染）。

### 4.2 防未来复发（需重新构建 exe 才生效）
- `app.py`：全部 HTML 路由 `Cache-Control: no-cache` → **`no-store`**（验证：响应头已含 `no-store`）。
- `launcher.py`：启动时 `_prof.clearHttpCache()`，每次启动清空可能残留的旧页缓存。

### 4.3 同步与校验
- 三份副本（`dashboard/`、`Release-Package/Resources/html/`、`KnowSubtle-Submission/source/dashboard/`）已同步，均 `SYNTAX_OK`、jsdom 复验 0 错误、`escHtml` 定义一致、无 `landing` 残留、4 处跳 `index`。

## 五、当前 exe 的恢复步骤（用户侧操作）

> 代码已修好，但**你正在跑的 exe 可能仍在用陈旧缓存/旧进程**。请按以下任一方案恢复：

**方案 A（推荐，无需重建）**
1. 完全退出 KnowSubtle（关窗口 + 确认无 `KnowSubtle.exe` 进程）。
2. 清空 QWebEngine 缓存（关闭 exe 后执行，任选其一）：
   - 删除文件夹 `%LocalAppData%\KnowSubtle`（QWebEngine 配置/缓存/登录态根目录）；
   - 或删除 exe 同级 `Release-Package\Core\KnowSubtle\QtWebEngine` 目录（若存在）。
3. 重新双击 `启动KnowSubtle.bat`。
4. 在 `index.html` 登录/注册，再点「智能学习」。

**方案 B（彻底）**
重新执行 `python build/build_exe.py` 构建 exe（已含 `no-store` + `clearHttpCache`），再启动。

**验证是否成功**
- 打开「智能学习」页，DevTools 控制台输入 `typeof escHtml` → 应返回 `"function"`（返回 `"undefined"` 说明仍是旧页，需再清缓存/硬刷）；
- 页面应正常显示「学习画像 / 资源中心 / 学习路径」三标签内容及对话输入框，无白屏、无报错。
