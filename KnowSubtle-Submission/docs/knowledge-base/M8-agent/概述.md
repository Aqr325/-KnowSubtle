# M8 智能体与大模型应用 · 模块概述

## 一、模块教学目标

本模块是课程的集成与前沿章，将前序感知（M6/M7）、推理（M3）、学习（M4/M5）能力汇聚为"能感知—思考—行动"的智能体（Agent），并介绍以大模型为中枢的当代应用范式。

完成本模块后，学生应能够：

1. 给出智能体（Agent）的定义与"感知—规划—行动—反馈"闭环；
2. 理解基于大语言模型（LLM）的智能体组成：规划、记忆、工具调用；
3. 掌握检索增强生成（RAG）的原理与价值；
4. 了解提示工程、思维链（CoT）、工具调用（Function Calling）等基本技术；
5. 认识智能体的典型应用与风险（失控、滥用、依赖幻觉）。

## 二、核心知识点清单

- 智能体定义：自治性、反应性、主动性、社会性
- LLM Agent 架构：规划（Planning）/ 记忆（Memory）/ 工具（Tools）
- 思维链（CoT）与 ReAct（推理+行动交织）
- 检索增强生成（RAG）：向量检索 + 上下文拼接 + 生成
- 工具调用与函数调用（Function Calling）、插件生态
- 多智能体协作（如辩论/角色分工）简介

## 三、与前后续模块的关系

- **前置综合**：M2 搜索/规划、M3 推理、M4/M5 学习、M6/M7 感知，全部汇流于此。
- **后续衔接**：M9 直接讨论智能体的安全对齐、失控与滥用风险，是本模块的"刹车系统"。

## 四、思政 / AI 素养融入点

1. **善用工具、人机协同**：智能体的价值在于"放大人的能力"而非替代人的判断，培养"以我为主、工具为辅"的主体意识。
2. **自主与可控**：Agent 的自治性越强，越需"人在回路（human-in-the-loop）"与可追溯，树立可控可信的工程伦理。
3. **负责任创新**：RAG/工具调用可显著降低幻觉，但部署仍须合规与审计，体现"能力越大责任越大"。

## 五、学习建议

建议画一张"LLM Agent 闭环图"：用户输入→规划→检索/工具→生成→执行→反馈。再亲手试一次 RAG（用本地文档检索 + 大模型问答），体会"给模型配上外部记忆"如何减少胡编。
