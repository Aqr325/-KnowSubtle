# M8 智能体与大模型应用 · 案例

## 案例一：检索增强生成（RAG）赋能课程知识库问答

**背景**：高校课程（如本门《人工智能导论》）积累了大量讲义、论文、习题。直接让通用大模型作答，易出现"编造概念、引用不存在的文献"的幻觉。RAG 把课程资料变成可检索的外部记忆，显著提升可靠性。

**技术点**：
1. **切分与向量化**：将知识库文档（如本套 9 模块 36 篇）按章节切分，用嵌入模型转为向量存入向量库；
2. **检索**：学生提问（如"什么是可采纳性启发式？"）经同模型编码，余弦相似度检索最相关片段；
3. **生成**：把检索片段拼入提示，要求模型"仅依据所给资料作答并标注出处"。

**启发**：
1. RAG 将"模型记忆"转为"检索 + 引用"，回答可溯源、可更新，是教育、法律、医疗等要求准确的场景首选。
2. 这正是 KnowSubtle 系统"课程知识库驱动个性化路径"的技术内核——把权威教材作为可信底座，大模型只做"编排与讲解"，既保准确又保个性。
3. 素养衔接：RAG 不是银弹——检索质量、切分粒度、上下文污染都会影响结果，须配合"防幻觉系统提示 + 免责脚注"双保险（见 M9/D2）。

## 案例二：AutoGPT / 多智能体协作的"自主任务执行"

**背景**：2023 年前后，AutoGPT 等实验性 Agent 让用户输入一个高层目标（如"调研某领域并写一份报告"），Agent 自主循环"规划→调搜索/写文件→检视"直至完成，展示了 LLM Agent 的自治潜力。

**技术点**：
- **ReAct 循环**：Thought（思考）→ Action（调用工具）→ Observation（观察结果）→ 下一轮 Thought，直至给出 Final Answer；
- **工具集**：网络搜索、文件读写、代码执行、API；
- **多 Agent**：研究者/写作者/评审者分工协作，互相纠错。

**启发**：
1. Agent 把"大模型的文本能力"升级为"面向目标的世界交互能力"，是从"聊天"到"干活"的关键一跃。
2. 自治带来新风险：实验显示 Agent 容易陷入无效循环、错误调用工具、产生高昂 token 成本，甚至被提示注入误导——印证 M9 对"可控性/人在回路"的强调。
3. 教育意义：鼓励学生把 Agent 当"实习生"——交代清楚目标、提供工具与边界、审阅其产出，而非盲目信任其自主结论。

> 小结：RAG 与自主 Agent 共同定义了"大模型应用"的两条主线——**让模型更可信**（接外部知识）与**让模型更能干**（接外部行动）。二者都指向"人在回路、可控可信"的落地原则。
