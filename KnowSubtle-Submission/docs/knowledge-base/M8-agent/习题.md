# M8 智能体与大模型应用 · 自测习题

## 一、选择题

**1.** 智能体的"自治性"是指（ ）
A. 必须有图形界面  B. 无需人类持续干预即可行动  C. 仅做分类  D. 必须联网
> 答案要点：B。

**2.** RAG（检索增强生成）主要用来缓解大模型的（ ）
A. 训练速度慢  B. 幻觉与知识截止  C. 显存不足  D. 词表太小
> 答案要点：B。

**3.** 让模型"一步步推理"的提示技术是（ ）
A. 数据增强  B. 思维链 CoT  C. 批归一化  D. 残差连接
> 答案要点：B。

## 二、简答题

**4.** 简述 LLM Agent 的三大组成模块及其作用。
> 答案要点：规划（把任务分解为步骤、推理，如 CoT/ReAct）；记忆（短期上下文 + 长期外部存储，跨会话保持知识）；工具（函数调用搜索/计算/API/代码，突破纯文本限制）。

**5.** 用三句话说明 RAG 的工作流程。
> 答案要点：先将文档切分向量化存入向量库；用户提问时检索最相关片段；把片段作为上下文拼入提示让模型据之生成，从而可溯源、可更新、降幻觉。

**6.** 什么是 ReAct 范式？相比纯思维链有何优势？
> 答案要点：ReAct 将推理（Thought）与行动（Action）交替进行：思考→调工具→观察→再思考；相比纯 CoT 仅内部推理，ReAct 能调用外部工具获取实时/真实信息，减少幻觉、处理需外部知识的任务。

## 三、分析题

**7.** 某教务系统用 RAG 接入课程大纲，但学生反映"答非所问且仍会编造章节名"。请列出至少三条可能原因与改进。
> 答案要点：原因/改进：①检索质量差（切分过大/嵌入模型不匹配）→优化切分与嵌入；②检索片段未真正拼入或提示未约束"仅据资料作答"→强化提示与引用；③未过滤无关结果→加重排(rerank)与相似度阈值；④仍缺防幻觉系统提示→加"不确定标[待核实]、不编造"约束与输出脚注。

**8.** 智能体"自治性"越强的潜在风险是什么？应如何设防？
> 答案要点：风险：错误/越权执行不可逆动作、陷入循环耗费资源、被提示注入操控、用户过度依赖丧失判断。设防：人在回路（关键动作需确认）、动作沙箱与权限最小化、操作日志与可回滚、输入输出安全过滤、明确失败兜底与人工接管机制（衔接 M9）。
