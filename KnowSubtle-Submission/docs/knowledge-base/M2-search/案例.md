# M2 搜索与问题求解 · 案例

## 案例一：迷宫路径规划中的 A* 算法（自动驾驶/机器人导航）

**背景**：移动机器人从起点到达目标点，需在有障碍的二维栅格环境中规划最短可行路径。这是搜索算法的典型落地场景，也是自动驾驶"局部路径规划"的简化模型。

**技术点**：
- 状态 = 机器人所在栅格坐标；动作 = 上/下/左/右移动；代价 = 步长（常取 1，斜向 $\sqrt{2}$）。
- 启发式函数常取**曼哈顿距离** $h=|x_{goal}-x|+|y_{goal}-y|$ 或**欧几里得距离**，二者均满足可采纳性（不高估真实剩余代价）。
- A* 用 $f=g+h$ 优先扩展"已走代价 + 预估剩余"最小的节点，相比 BFS/UCS 显著减少扩展节点数。

**启发**：
1. 启发式质量直接决定效率——距离函数选得越贴合可通行地形，剪枝越强；但必须保持"可采纳"以保证最优。
2. 现实中还需考虑动态障碍、运动学约束，引出"图搜索 + 采样（如 RRT）"等进阶方法，但 A* 是理解一切的基石。
3. 思政映射：方法的选择体现"在有限资源下追求最优"的工程权衡智慧。

## 案例二：IBM 深蓝（Deep Blue）与对抗搜索（1997）

**背景**：1997 年 IBM 深蓝以 3.5:2.5 战胜国际象棋世界冠军卡斯帕罗夫，是 AI 在复杂博弈中首次击败在位世界冠军的标志性事件。

**技术点**：
- 国际象棋可形式化为博弈树：MAX（电脑）与 MIN（对手）轮流落子，叶节点用评估函数（子力、位置、王安全等）打分。
- 深蓝结合**极小化极大 + 大规模 α-β 剪枝**，辅以专用硬件实现每秒上亿节点搜索，并融入开局库与残局库。
- α-β 剪枝使其在不损失最优性的前提下，将有效搜索深度从 $O(b^d)$ 降到约 $O(b^{d/2})$。

**启发**：
1. 深蓝证明：即便搜索空间巨大，借助"剪枝 + 领域知识（评估函数）"仍可在有限算力下逼近最优决策。
2. 它也揭示了早期博弈 AI 的局限——依赖人类专家设计的评估函数与手工特征，与后来 AlphaGo 的"端到端学习"路线形成对照，体现技术范式演进。
3. 素养启示：博弈思维不仅用于游戏，也用于竞价、调度、安全攻防等对抗性决策，理解 Minimax 有助于识别"零和思维"的局限，转向更优的合作解。

> 小结：从迷宫寻路到博弈对弈，搜索把一个"如何达到目标"的模糊问题转化为可计算的状态空间遍历——这是人工智能最早也最可解释的问题求解范式。
