# M4 机器学习基础 · 案例

## 案例一：垃圾邮件过滤中的朴素贝叶斯（产业经典）

**背景**：早期 Gmail、Outlook 等邮件系统的垃圾邮件（spam）过滤，广泛采用朴素贝叶斯分类器。它要在"正常邮件/垃圾邮件"二分类上做到高召回且不误杀重要邮件。

**技术点**：
- 将邮件表示为词袋（Bag-of-Words）特征。
- 基于贝叶斯公式求后验：
  $$P(\text{spam}\mid \text{words})=\frac{P(\text{spam})\prod_i P(w_i\mid\text{spam})}{P(\text{words})}$$
  其中"朴素"假设：各词在给定类别下条件独立。
- 用平滑（如拉普拉斯平滑）避免某词未出现导致概率乘零。

**启发**：
1. 一个"强假设（条件独立）不成立"的简单模型，在实践中仍极有效，说明**先验知识与工程取舍**的重要性。
2. 评估不能只看准确率——把正常邮件误判为垃圾（FP）代价很高，需权衡精确率与召回率，引出"误杀代价"的业务意识。
3. 当今垃圾过滤已融合深度学习，但朴素贝叶斯因其可解释、小样本可用、易更新，仍是基线模型与教学范例。

## 案例二：Netflix 推荐与协同过滤（无监督/矩阵分解思路）

**背景**：Netflix 百万美元竞赛（2006–2009）推动了矩阵分解（如 SVD++）在推荐系统中的应用，目标是预测用户对未看影片的评分。

**技术点**：
- 用户—物品评分矩阵稀疏，需从已知评分推断未知（典型的"预测"问题，可视为监督回归或矩阵补全）。
- 核心思想：将高维稀疏矩阵近似分解为**用户隐向量** $U$ 与**物品隐向量** $V$，使 $R\approx U V^\top$，预测分 $\hat r_{ui}=u_u^\top v_i$。
- 优化目标常加正则项防止过拟合：
  $$\min_{U,V}\sum_{(u,i)\in\text{已知}}(r_{ui}-u_u^\top v_i)^2+\lambda(\|U\|^2+\|V\|^2)$$

**启发**：
1. 推荐系统本质是"从行为数据学习偏好结构"，是机器学习从"标注"走向"隐变量建模"的代表。
2. 正则化（$\lambda$ 项）对泛化至关重要——竞赛中过拟合训练集的模型在测试集上惨败，正是本模块"偏差—方差"理论的真实写照。
3. 素养延伸：推荐算法会造成"信息茧房"、强化偏见，这把 M4 的技术问题与 M9 的伦理问题直接勾连，提醒学习者技术选择内含价值导向。

> 小结：从朴素贝叶斯到矩阵分解，机器学习展示了"用数据替代手工规则"的范式转变，也把"如何评估、如何防过拟合、如何负责任"的方法论课题摆在了每位使用者面前。
