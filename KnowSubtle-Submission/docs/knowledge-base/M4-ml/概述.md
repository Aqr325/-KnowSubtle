# M4 机器学习基础 · 模块概述

## 一、模块教学目标

本模块从"符号手工编码"转向"从数据中自动学习"，是连接主义与 contemporary AI 的枢纽。学生将理解机器学习的基本范式、核心算法与评估方法。

完成本模块后，学生应能够：

1. 区分监督学习、无监督学习、强化学习三类范式；
2. 理解线性回归、逻辑回归、决策树、SVM、聚类等基本模型；
3. 掌握损失函数、经验风险最小化与梯度下降优化；
4. 理解过拟合/欠拟合、训练/验证/测试划分、正则化等关键概念；
5. 认识模型评估指标与偏差—方差权衡。

## 二、核心知识点清单

- 学习范式：监督 / 无监督 / 强化
- 线性模型：线性回归、逻辑回归（sigmoid）
- 损失函数：MSE、交叉熵（Cross-Entropy）
- 优化：梯度下降（BGD/SGD/mini-batch）、学习率
- 模型评估：准确率、精确率、召回率、F1、ROC-AUC；过拟合与正则化
- 经典算法：决策树、k-近邻、k-means 聚类、朴素贝叶斯

## 三、与前后续模块的关系

- **前置**：M3 提供符号/概率基础；本模块是统计学习视角。
- **后续衔接**：
  - M5 深度学习是"用深层神经网络"的机器学习特例；
  - M6/M7 将 ML 应用于语言/视觉特征学习；
  - M8 强化学习作为第三范式在智能体中展开；
  - M9 关注模型偏见、隐私与稳健性。

## 四、思政 / AI 素养融入点

1. **数据素养与实证精神**：模型性能依赖数据质量，"垃圾进垃圾出"，培养尊重数据、质疑样本偏差的科学态度。
2. **辩证看能力边界**：过拟合揭示"记忆≠学会"，类比学习中的死记硬背，引导学生追求可泛化的真理解。
3. **公平与责任**：训练数据的偏见会被模型放大（如招聘/信贷歧视），引出算法公平的社会责任议题。

## 五、学习建议

建议用一小份二维数据手算一次梯度下降（如单变量线性回归），体会"沿负梯度下山"的几何直觉；再用 scikit-learn 跑通一个分类管线，对比不同模型指标。
