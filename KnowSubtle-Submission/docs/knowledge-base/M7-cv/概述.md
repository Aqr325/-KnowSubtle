# M7 计算机视觉 · 模块概述

## 一、模块教学目标

本模块将深度学习（M5）应用于图像与视频，介绍让机器"看见并理解"视觉世界的任务、模型与范式，从图像分类到目标检测、分割与多模态。

完成本模块后，学生应能够：

1. 列举计算机视觉的核心任务（分类、检测、分割、识别）；
2. 理解 CNN 在视觉中的特征层级与经典网络（LeNet/AlexNet/VGG/ResNet）；
3. 掌握目标检测（边界框、anchor）与语义/实例分割的基本思想；
4. 了解视觉 Transformer（ViT）与 CNN 的对照；
5. 认识视觉应用的伦理风险（监控、偏见、深度伪造）。

## 二、核心知识点清单

- 图像表示：像素、通道（RGB）、卷积特征图
- CNN 经典架构：LeNet → AlexNet → VGG → ResNet（见 M5 残差）
- 数据增强与过拟合控制
- 目标检测：R-CNN 系列、YOLO（单阶段）；边界框与 IOU
- 图像分割：语义分割（FCN）、实例分割（Mask R-CNN）
- 视觉 Transformer（ViT）与多模态（图文对齐，衔接 M8）

## 三、与前后续模块的关系

- **前置**：M4（分类/损失）、M5（CNN/Transformer）是技术基础。
- **后续衔接**：
  - M8 智能体常需"视觉感知"输入（如具身智能、文档理解多模态 Agent）；
  - M9 关注监控滥用、偏见、深度伪造（Deepfake）等风险。

## 四、思政 / AI 素养融入点

1. **科技服务民生**：视觉技术在医疗影像（辅助诊断）、农业（病害识别）、无障碍（视障辅助）中的正向价值。
2. **隐私与边界意识**：人脸识别的便利与监控滥用风险并存，培养"技术中立但使用有责"的法治与伦理观。
3. **辨别虚假信息**：深度伪造使"眼见未必为实"，提升媒介素养与溯源意识。

## 五、学习建议

建议用 CNN 可视化（如各层激活图）观察"边缘→纹理→部件→物体"的特征层级；再跑一个目标检测 demo，理解边界框与 NMS（非极大值抑制）。
