# M7 计算机视觉 · 核心知识点

## 1. 图像的数学表示

图像通常为三维张量 $H\times W\times C$（$C$=通道，彩色 RGB $C=3$），像素值 $[0,255]$ 或归一化到 $[0,1]$。CNN 把图像作为"网格信号"处理，利用局部性与平移不变性。

## 2. 卷积与特征层级（温习 M5）

卷积核在图像上滑动提取局部特征；**池化**降采样；深层网络形成层级表示：浅层→边缘/颜色，中层→纹理/部件，深层→物体/语义。

> 关键结论：CNN 的归纳偏置（局部性 + 权值共享）极契合图像，是其成功主因；这也意味着它对全局长程关系捕捉弱于注意力。

## 3. 经典架构演进

- **LeNet-5（1998）**：最早的卷积网络之一，用于手写数字识别。
- **AlexNet（2012）**：在 ImageNet 上大幅领先，引爆深度学习，关键：ReLU、Dropout、GPU 训练、数据增强。
- **VGG（2014）**：用小 $3\times3$ 卷积堆叠加深网络。
- **ResNet（2015）**：残差连接突破深度瓶颈（详见 M5 案例一）。

## 4. 目标检测

任务：在图中定位并分类多个物体。表示物体为**边界框** $(x,y,w,h)$。

- **两阶段**（如 R-CNN/Fast/Faster R-CNN）：先提候选区域（region proposal），再分类与回归框。
- **单阶段**（如 YOLO、SSD）：直接在全图网格上预测框与类别，速度快，适合实时。
- **IOU（交并比）**：预测框与真值框交集面积 / 并集面积，是检测质量基本度量；常以 IOU>0.5 判为命中。
- **NMS（非极大值抑制）**：抑制高度重叠的冗余框，保留得分最高者。

## 5. 图像分割

- **语义分割**：为每个像素分配类别（如"路/车/人"），常用全卷积网络（FCN）、U-Net。
- **实例分割**：在语义分割基础上区分同类不同个体（如两辆车分属不同实例），代表 Mask R-CNN。

> 易错点：语义分割不区分个体；实例分割才区分"哪辆车是哪一辆"。

## 6. 视觉 Transformer（ViT）

将图像切为若干**图块（patch）**序列，像词序列一样送入 Transformer 编码。大规模数据下 ViT 可匹敌甚至超越 CNN，说明"通用注意力架构"的跨模态潜力。

## 7. 多模态与图文对齐（衔接 M8）

通过对比学习（如 CLIP）把图像与文本映射到同一表示空间，实现"以文搜图""图像描述生成"，是多模态大模型（图文理解 Agent）的基础。

## 8. 主要风险（衔接 M9）

- **偏见**：训练数据不均衡导致对某些群体识别误差更大；
- **隐私**：无感人脸识别与大规模监控；
- **深度伪造（Deepfake）**：生成逼真换脸/换声，挑战证据可信度。
