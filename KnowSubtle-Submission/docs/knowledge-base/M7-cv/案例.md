# M7 计算机视觉 · 案例

## 案例一：ImageNet 与 AlexNet 引爆深度学习（2012）

**背景**：2012 年，Krizhevsky 等的 AlexNet 在 ImageNet 大规模视觉识别挑战赛（ILSVRC）上以 top-5 错误率约 15.3% 夺冠，比第二名（26.2%）低逾 10 个百分点，被视为深度学习引爆点。

**技术点**：
- 8 层 CNN（5 卷积 + 3 全连接），使用 **ReLU** 激活加速训练；
- **Dropout** 抑制全连接层过拟合；
- 在两块 GPU 上并行训练，借助 ImageNet 百万级标注图像与数据增强（翻转、裁剪）；
- 网络结构借鉴 LeNet 但显著加深加宽。

**启发**：
1. 这次胜利是"大数据（ImageNet）+ 深网络（AlexNet）+ 算力（GPU）+ 算法技巧（ReLU/Dropout）"四要素的共振，印证了 M5 所述"三要素积累"论断。
2. 它直接开启了 CNN 架构竞赛（VGG/GoogLeNet/ResNet），并外溢到语音、NLP，是第三次 AI 浪潮的核心引擎之一。
3. 素养启示：模型突破依赖高质量标注数据这一"基础设施"，凸显数据工程与开放数据集的公共价值。

## 案例二：YOLO 实时目标检测与产业落地

**背景**：2015 年起的 YOLO（You Only Look Once）系列将目标检测重构为"单次前向预测"，在保持可用精度的同时实现实时（数十 FPS），广泛用于自动驾驶感知、工业质检、安防。

**技术点**：
- 将图像划分为 $S\times S$ 网格，每格预测若干边界框与类别概率，**单阶段一次性输出**，省去候选区域生成。
- 损失涵盖坐标误差、置信度误差、分类误差；推理后经 **NMS** 去除重叠框。
- 后续版本（YOLOv3–v8）在多尺度、anchor 设计、速度—精度权衡上持续改进。

**启发**：
1. "把检测当回归问题一次性解决"展示了**范式重构**带来的数量级效率提升，是工程取舍（精度换速度）的经典范例。
2. 实时视觉感知是自动驾驶、机器人（M8 具身智能）的"眼睛"，说明 CV 不是孤立技术，而是智能体闭环的关键感知环节。
3. 风险衔接：检测/识别一旦用于无感监控或带有群体偏见，即触及 M9 的隐私与公平红线，技术部署须有治理框架。

> 小结：从 ImageNet 的"看得准"到 YOLO 的"看得快"，计算机视觉把像素转化为结构化理解，成为智能系统感知物理与数字世界的基石，也为多模态智能体（M8）准备了眼睛。
