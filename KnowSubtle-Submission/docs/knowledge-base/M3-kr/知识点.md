# M3 知识表示与推理 · 核心知识点

## 1. 知识表示的基本准则

- **表达充分性**：能表达待求解领域所需知识；
- **推理高效性**：便于计算机有效推导；
- **可维护性**：易于增删改；
- **可理解性**：人能读懂、审计（可解释性）。

> 关键结论：不存在"最好"的通用表示，"合适"取决于任务与推理需求。

## 2. 一阶谓词逻辑（First-Order Logic, FOL）

基本成分：
- **常量/变量/函数**：如 `King(x)`、`Father(John)`；
- **谓词**：表示关系或性质，如 `Loves(x,y)`；
- **联结词**：$\land$（与）、$\lor$（或）、$\neg$（非）、$\rightarrow$（蕴含）；
- **量词**：$\forall x$（对所有 $x$）、$\exists x$（存在 $x$）。

示例："所有人都会死"表示为 $\forall x\,(\text{Human}(x)\rightarrow\text{Mortal}(x))$。

> 易错点：混淆 $\forall x(P(x)\rightarrow Q(x))$ 与 $\exists x(P(x)\land Q(x))$。前者说"凡是 P 都是 Q"，后者说"存在既是 P 又是 Q 的个体"。

## 3. 产生式系统（Production System）

由三部分组成：
- **事实库（Working Memory）**：当前已知事实集合；
- **规则库**：形如 `IF 条件 THEN 结论/动作`；
- **推理机**：决定应用哪些规则。

两种推理方向：
- **前向链（Forward Chaining）**：从已知事实出发，反复触发规则直至目标或不再变化（数据驱动，常用于监控/诊断）。
- **后向链（Backward Chaining）**：从待证目标反推需要哪些前提（目标驱动，常用于问答/证明）。

## 4. 归结原理（Resolution）

命题逻辑中，由子句 $A\lor B$ 与 $\neg B\lor C$ 可推出 $A\lor C$。对一阶逻辑扩展为带"合一（Unification）"的归结。

**反证法思路**：要证明 $KB\models\alpha$，等价于证明 $KB\land\neg\alpha$ 不可满足（推出空子句 $\Box$）。

> 易错点：归结是**完备**的定理证明方法（能证出所有可证结论），但可能不终止；它证明"可满足性"，常借助反证。

## 5. 语义网络与框架

- **语义网络**：用图（节点=概念，边=关系）表达知识，直观但推理依赖遍历、易语义模糊。
- **框架（Frame）**：以"槽（slot）—填充值"结构描述典型情境（如"餐厅"框架含 预订/菜单/付款 槽），适合默认推理。

## 6. 知识图谱

以"实体—关系—实体"三元组 $(h,r,t)$ 存储知识（如 `(北京, 是首都, 中国)`）。当代知识图谱（Wikidata、CN-DBpedia 等）支撑搜索、推荐、问答，并可与表示学习（M4/M6）结合做链接预测。

> 关键结论：符号表示提供**可解释、可编辑**的知识，而向量/统计表示提供**可泛化、可学习**的模式，二者互补是"神经—符号"融合的核心动机。
