# M3 知识表示与推理 · 模块概述

## 一、模块教学目标

本模块承接符号主义传统，研究"如何把世界知识形式化地表示出来，并基于这些表示进行自动推理"。这是早期 AI（专家系统时代）的核心，也是当代知识图谱、可解释 AI 的基础。

完成本模块后，学生应能够：

1. 理解"知识表示"为什么是 AI 的关键子问题；
2. 掌握一阶逻辑的基本语言（常量、谓词、量词、联结词）；
3. 了解产生式规则、语义网络、框架等典型表示方式；
4. 理解前向链/后向链推理与归结原理的基本思想；
5. 认识符号推理的可解释优势及其与机器学习的互补关系。

## 二、核心知识点清单

- 知识表示的准则：表达充分性、推理高效性、可维护性、可理解性
- 一阶谓词逻辑：项、原子、公式、全称量词 $\forall$、存在量词 $\exists$
- 产生式系统：规则（IF–THEN）、事实库、推理机
- 逻辑推理：命题逻辑推理、归结原理（Resolution）
- 语义网络与框架（Frame）
- 知识图谱简介及其与机器学习的关系

## 三、与前后续模块的关系

- **前置**：M2 将问题形式化为状态空间；M3 把"状态/知识"显式表示为符号。
- **后续衔接**：
  - M4/M5 机器学习用统计方法补足"难以手工编码"的知识（如感知特征）；
  - M8 智能体在知识图谱/规则约束下做决策；
  - M9 伦理规则常编码为可执行的策略约束。

## 四、思政 / AI 素养融入点

1. **严谨的逻辑素养**：推理的有效性依赖前提真实与形式正确，引导学生区分"逻辑正确"与"结论正确"。
2. **知识主权与自主可控**：知识图谱作为关键数字基础设施，其构建权、数据权关乎信息安全，呼应科技自主。
3. **人机互补认知**：符号系统可解释但难覆盖常识，连接主义能学但难解释——培养"扬长避短、混合智能"的系统观。

## 五、学习建议

可从"家谱关系""动物分类"等小例子入手，先用产生式写几条规则（如"会飞且下蛋→鸟"），再尝试用一阶逻辑表达，体会"表示方式决定推理难易"。
