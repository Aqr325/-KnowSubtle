# M6 自然语言处理 · 核心知识点

## 1. 自然语言的层次与任务

- **词法**：分词、词性标注（POS）；
- **句法**：短语结构/依存句法分析；
- **语义**：词义消歧、语义角色标注；
- **语用/应用**：命名实体识别（NER）、情感分析、机器翻译（MT）、问答（QA）、摘要、对话。

> 关键结论：语言具有**歧义性、稀疏性、组合性**，这是 NLP 比视觉更难的深层原因。

## 2. 词表示：从独热到词向量

- **独热（One-hot）**：维度=词表大小，正交、无相似度。
- **词向量（分布式表示）**：将词映射为低维稠密向量，相似词向量相近。

**Word2Vec（Skip-gram）**目标：给定中心词预测上下文，最大化

$$\frac1T\sum_{t=1}^T\sum_{-c\le j\le c,j\ne0}\log P(w_{t+j}\mid w_t)$$

其中 $P(w_o\mid w_c)=\frac{\exp(v_{w_o}^\top u_{w_c})}{\sum_{w}\exp(v_w^\top u_{w_c})}$。

**分布假设**："出现在相似上下文的词义相近"，故向量可编码语义类比（king−man+woman≈queen）。

## 3. 序列建模演进

- **RNN/LSTM**：早期主力，但并行差、长程弱；
- **CNN-for-text**：以一维卷积提取 n-gram 特征；
- **Seq2Seq + 注意力**：编码器将源句压为向量，解码器逐词生成，注意力解决"信息瓶颈"。

## 4. Transformer 在 NLP 的两大流派

- **BERT（编码器）**：双向，预训练任务为**掩码语言模型（MLM）**——随机遮掩部分词让模型预测，学到深上下文表示，适合理解类任务（分类、抽取、QA）。
- **GPT（解码器）**：单向**自回归**，依前缀预测下一词 $P(x_t\mid x_{<t})$，适合生成类任务（续写、对话、翻译生成）。

> 易错点：BERT 因双向可见，不能直接用于"预测下一个词"的自回归生成；GPT 因单向，对"完形填空"类理解任务不如 BERT。

## 5. 评测指标

- **困惑度（Perplexity）**：语言模型越低越好，$PP=2^{-\frac1N\sum\log_2 P(w_i)}$。
- **BLEU**（翻译）：基于 n-gram 精确率与 brevity penalty。
- **ROUGE**（摘要）：基于 n-gram 召回率。
- 近年趋势：用 LLM 做裁判（LLM-as-Judge）但仍需人工校准。

## 6. 提示与指令微调（衔接 M8）

不再为每个任务训练模型，而是用**提示（Prompt）**描述任务，配合**指令微调（SFT）**与 **RLHF** 让模型遵循指令、对齐人类偏好。这把 NLP 从"一对多模型"推向"一个基础模型+自然语言接口"。

## 7. 主要局限

- **幻觉**：生成看似通顺但事实错误的内容；
- **偏见与毒性**：习得语料中的刻板印象；
- **脆弱性**：对措辞敏感、缺乏真实世界 grounding。
