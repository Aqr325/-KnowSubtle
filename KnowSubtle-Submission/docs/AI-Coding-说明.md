# AI Coding 工具使用说明

本项目（**KnowSubtle 个性化学习多智能体系统**）在开发全过程大量使用 AI Coding 工具辅助，以提升工程效率与质量。现按参赛要求，对所使用的 AI 编程工具及其在项目中承担的角色作如实说明。

## 一、使用的 AI 编程工具

| 工具 | 类型 | 在项目中承担的角色 |
|------|------|-------------------|
| **Claude Code CLI + CC-Switch + Agnes API** | 命令行 AI 编程智能体 | 核心编码助手：负责后端（FastAPI 端点、SSE 流式、真实 LLM 代理层）、前端（单文件 SPA 仪表盘）、桌面端（PyQt6 打包）的主体实现与迭代调试 |
| **WorkBuddy** | 多智能体协作工作台 | 团队化调度：以"主理人 + 领域专家"模式并行编写参赛文档套件（需求/设计/测试/用户手册/综述）、构造课程知识库、执行一致性核查 |
| **PinMe 技能包** | 对话式网站部署技能 | 辅助将前端资产与文档预览/部署到可访问环境 |
| **GitHub Copilot / 静态分析辅助** | 代码补全与检查 | 局部代码补全、单元测试与 `py_compile`/`node --check` 校验辅助 |

> 说明：上述工具均为"人机协作"模式——所有关键架构决策、 factual 内容（课程知识库、防幻觉规则、内容安全分类）均由人工审核与校验，AI 仅承担生成与加速职能，最终代码与文档经人工复核后落盘。

## 二、AI Coding 在关键模块中的具体应用

1. **个性化学习后端（流式 + 防幻觉 + 安全）**
   - 由 Claude Code 在 `app.py` 中实现 `call_llm` / `call_llm_stream`、`POST /api/profile/converse/stream` 与 `/api/resources/generate/stream` 两个 SSE 端点、`ANTI_HALLUCINATION` 系统提示与 `RESOURCE_FOOTNOTE` 资源脚注。
   - 内容安全模块 `learning_agent_system/moderation.py`（9 类离线启发式过滤）由 AI 生成初稿，人工核对分类与正则准确性。

2. **前端单文件 SPA（learning.html）**
   - 由 AI 生成三标签界面（学习画像 / 资源中心 / 学习路径）、流式渲染（`fetch` + `ReadableStream` 解析 SSE）、多模态卡片化与 `escHtml` XSS 防护；人工校验交互逻辑与离线可用性。

3. **桌面端打包（PyQt6 + PyInstaller）**
   - AI 辅助编写 `build/build_exe.py` 与 `launcher.py`，处理 cffi 扩展收集、GPU 合成渲染开关、单实例 PID 锁等打包陷阱；人工验证 exe 在隔离环境独立运行。

4. **参赛文档与课程知识库（WorkBuddy 多智能体）**
   - 由"主理人"调度软件架构师、技术写作者、AI 工程师等专家角色并行撰写 D1–D5 标准文档与《人工智能导论》36 篇知识库；主理人负责跨文档事实一致性核查（如统一 7 类资源命名、修正无据数据）。

## 三、人工把关与质量保障

- **事实准确性**：课程知识库公式与术语按高校《人工智能导论》水准人工核对；防幻觉机制要求系统对不确定内容标注 `[待核实]`，不编造引用。
- **安全合规**：内容安全 9 类过滤、开源协议（`docs/ATTRIBUTION.md` 显著标注 11 项依赖名称/来源/协议，含 PyQt6 GPLv3 商业许可提示）均由人工复核。
- **可运行性**：提交包在常规 Python 3.11+ 环境经 `py_compile` 全量编译、Mock 流式 12 断言、前端 `node --check`、实服冒烟（401/400/200）验证。
